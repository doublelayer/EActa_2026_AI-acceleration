# Article-generation entry point

Execute PROMPT.txt from this directory. Read instructions/INDEX.md and article/input_manifest.json, then follow the declared role turns. The root contains this router, the prompt, four source notebooks, the comparison reference DOCX and supporting subfolders. Read role descriptions in instructions/. Supporting scripts are in tools/. Use the supplied workspace-root scientific databases and prediction CSV through their declared relative paths; do not download or copy them. Save every generated file, cache, temporary file and execution copy under inputs/. Keep manuscript and review files in inputs/run_.../. The root reference DOCX is reserved for human comparison after generation and excluded from drafting, review and construction. Follow the network policy in PROMPT.txt. Parent-project manuscripts and historical instructions are outside this isolated run.
