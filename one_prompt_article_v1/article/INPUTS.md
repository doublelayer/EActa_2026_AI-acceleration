# Inputs

The input manifest records fingerprints for the five source DASC databases in the parent project. Other supplied generation inputs are documented below and tracked by Git. Four notebooks are at the root. The TOC generator is tools/create_graphical_abstract_v32.py and its publication-page image is source_data/reference_EActa_open_article_2020_page1.png. Instructions, article facts, literature summaries and journal guidance occupy their named subfolders.

The five ASE databases are read directly from the parent project root. The input manifest records their SHA-256 fingerprints only; a changed or missing database raises an alert for review. Figure 4 reads `predictions.csv`, `structure_model_roles.csv`, `model_structure_descriptors.csv`, and `split_config.json` from `source_data/figure4/`. These supplied files are tracked by Git and checked separately by the applicable Figure 4 analysis verification. Database loaders check the SQLite signature; they do not enforce manifest SHA-256 baselines. No scientific input is downloaded. All generated outputs go under inputs/. The root reference DOCX is excluded from generation and retained for later human comparison.
