# Package layout

The root contains PROMPT.txt, AGENTS.md, four figure-generation notebooks and Electrochimica_Acta_research_article_refernce.docx. The reference is reserved for human comparison after generation and excluded from drafting inputs.

instructions/ contains role and writing guidance. article/ contains facts, bibliography, sentence plan and the database-only input manifest. journal/, literature/ and environment/ contain their declared supporting inputs. tools/ contains the database fingerprint check and TOC generator. source_data/ contains the supplied publication-page image and the Figure 4 source bundle in `source_data/figure4/`. The notebooks and TOC generator read DASC databases from the parent project root and Figure 4 CSV/JSON inputs from the package; none of these inputs are downloaded. inputs/ starts empty and receives every generated file.

Run `python tools/verify_package.py` to compare the five source database fingerprints with `article/input_manifest.json`; a changed or missing database produces an alert and does not fail the check. This verifier does not inspect other files. Verify notebooks, generated figures, the manuscript and other artifacts through their separate checks; Git tracks file changes. Run `python tools/prepare_manifest.py` to remove unrelated entries while preserving unchanged database baselines. Use `python tools/prepare_manifest.py --accept-current` only after reviewing and intentionally accepting changed database sources. Execute the four root notebooks and then `python tools/create_graphical_abstract_v32.py` from this directory, as directed in PROMPT.txt. An independent article-generation test has not yet run.
