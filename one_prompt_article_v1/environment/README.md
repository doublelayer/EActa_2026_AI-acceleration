# Environment

requirements.in lists suggested installed packages, not a tested lockfile. No GPAW installation is needed to inspect saved data or write the article. ASE is needed for atomic databases and molecular/DFT notebooks. Figure 4 reads local CSV inputs and needs no ASE. POV-Ray is needed to rerender Figure 2. Scientific inputs are read from the parent project root and `../figure4/`; no GitHub data downloads are used. Record environment limitations and use supplied approved artwork when rerendering is unnecessary.
