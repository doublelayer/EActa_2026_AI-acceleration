# Environment

requirements.in lists suggested installed packages, not a tested lockfile. No GPAW installation is needed to inspect saved data or write the article. ASE is needed for atomic databases and molecular/DFT notebooks. Figure 4 reads local CSV inputs from `source_data/figure4/` and needs no ASE. POV-Ray is needed to rerender Figure 2. DASC database inputs are read from the parent project root; Figure 4 inputs are packaged locally. No GitHub data downloads are used. Record environment limitations and use supplied approved artwork when rerendering is unnecessary.
