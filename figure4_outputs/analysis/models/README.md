# 20261016 models

Run from `article/KongiCats/20261016`:

```powershell
python models\build_models.py
```

The builder reads `descriptors/model_all_structures_training_data.csv` and checks each row's `split` against the target-specific assignments in `descriptors/model_all_structures_split.csv`. These files are generated by `descriptors/extract_model_dataset.py` from `descriptors/structure_model_roles.csv`. The separate `descriptors/model_structure_descriptors.csv` contains site descriptors for every bare structure, including prediction-role structures.

The labeled fitting table has 70 training and 13 validation site rows for each target, grouped across 50 training and 10 validation structures. The builder selects predictors and ridge strength from training rows only. Ridge alpha is selected from `0` and `10^-4` through `10^4` in half-decade steps by mean RMSE over three repeats of five-fold cross-validation grouped by structure name. Missing predictors are imputed with training-row medians; scaling and coefficients are fitted on training rows only.

The builder writes `alpha_selection.csv`, `final_model_parameters.csv`, `model_metrics.csv`, `predictions.csv`, `validation_predictions.csv`, `cv_predictions.csv`, `model_bundle.json`, and `run_config.json` beside this README. It records the input paths, role columns, selected predictors, alpha grid, and CV settings in `run_config.json`.

Refresh observed-versus-predicted plots with:

```powershell
python models\plot_training_validation_regressions.py
```

The plot script writes one combined plot and one two-panel plot per target into `models/regression_plots/`.
